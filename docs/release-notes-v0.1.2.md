# v0.1.2 · 剧本重写：让她读起来像一个正在打字的人

这一版没有新功能。改的是**她说的话**。

真机玩家的第一个反馈是：**"我觉得对话的 AI 味太重了。"** 这句话没法用日志证明，
但能拆开数。我把全篇 182 个节点、481 条她的气泡逐条过了一遍——机器味在这里是有形状的：

1. **每段都要收一个金句**。"没关系。我会等。等得挺熟练的。"
   "它不告诉我。它比我还有礼貌，起码我还会回话。"
   一段一次是风格，每段一次就是模板——深夜打字的人不逐段修辞。
2. **句长整齐得不像聊天**。只数她的气泡：旧稿 481 条，平均一条 **21.2 字**，6 字以内的只有
   **8.1%**；D5 一章 69 条里**一条短句都没有**（均长 31.8 字），D4 八十四条里只有三条是碎的。
   真人聊天是双峰的：一大半是「你」「好的」「没了」，偶尔冒出一整段停不下来的话。旧稿是一座匀速的小山。
3. **同一个反转句式复读**。「不是X。是Y。」旧稿全篇 **16 次**：D6 一章六次，D1、D3、D7 各三次
   （D1："不是坏了。是那些房没了。"＋"不是删了。是那一栏整个不在。"＋"它不是被拆了。它是一直都是墙。"）。
4. **自我点评**。"哦，对，礼貌。我忘了礼貌。""我不算了，算了不好看。"
   "我松了口气。真的。"——角色替观众解释自己为什么这么说，这是生成文本最稳的习惯。
5. **同一句话说两遍**（这条是真 bug，不是风格）。引擎在等待到点时先贴
   `wait.first_line_after_wait`（它同时是通知栏那句文案），再走下一个节点的正文。
   旧稿有 **8 处**两边内容重合，其中 6 处逐字相同——D1 的门锁、D1 那 141 遍、D3 的那层楼、
   D4 的电闸、D4 的电梯、D5 的那只盒子。**她每次从等待里回来都把同一句话原样再发一遍**，
   七章每章一到四个等待，这是全篇最刺眼的机器感。

## 改了什么

七章的 `text` 数组全部重写（她的气泡从 481 条变成 682 条；节点 id / `next` / `choices` /
`delay_ms` / `effects` / `flags` / 等待时长一个没动）：

- 删掉逐段金句，改成话说一半、拐去别处、或者干脆不说完；
- 打散句长：**≤6 字短句占比从 8.1% 提到 18.5%**，全书均长从 21.2 字降到 13.4 字，
  最长那章（D5）从 31.8 字降到 14.8 字；
- 「不是X。是Y。」从 16 次降到每章 ≤2 次，只留在真正需要的地方（D3 那半秒停顿、D6「我不是没长大。我是没往下长。」）；
- 自我点评全删，情绪只靠句子变短和答非所问（圣经规则 9 本来就这么要求，是旧稿没执行）；
- "哈哈哈哈"一律单独成条、后面跟一句真话（圣经规则 8；旧稿 8 条带「哈哈」的气泡里
  只有 1 条是独立的一句，剩下 7 条都跟真话挤在同一条里，比如
  「哈哈哈哈你这个人很讲道理，我喜欢讲道理的……」——人在笑的时候不会一边笑一边打字）；
- 塞进无用的话：找不着的扣子用别针顶、早饭吃什么、把手写纸贴到电梯按钮上——
  不为氛围服务的那部分，才是人；
- 等待复读：这 8 处的承接句只留在 `wait` 上（它同时是通知文案），下一节点从第二句开始说。

三封灭屏信按圣经备忘统一以"你在"开头（D5 那封解释了这两个字为什么写在头一行，
旧稿只有它自己有——现在三封都有）。

## 为什么这些改动现在能被守住

新增 `ScriptVoiceTest`（4 条），把上面第 2、3、5 条变成会红的断言：

- 等待承接句与下一节点正文不许相同或互为前缀；
- 每章 ≤6 字气泡不少于 12%、全书不少于 15%、单章均长不超过 20 字；
- 单章「不是X。是Y。」不超过 2 次；
- "哈哈哈哈"必须独占一条，且下一条是真话。

阈值取的是这次改完的实测值再留一档余量——往回滑就红，不靠读者"感觉一下"。
剧本自带的 `tools/validate_script.py`（120 字上限、省略号密度、标点堆叠）与
`tools/audit_continuity.py`（跨章回指对账）也全部重跑：63 条单测 0 失败，七章 PASS。
五个形状的改前改后对照与量法口径，记在 `docs/07` 第七节。

## 没有动的

剧情、事件顺序、分支与度量账、七个结局、存档格式、唤醒链路、声床编排、六秒人声、
所有 `note` 里钉住"位置不可改"的原句：`我明天还要早起面试`（D1/D2/D7 与《残片》共用）、
`会想的人有明天`（D6 逐字反噬）、`我这边能亮的就剩两样。一盏灯，一个你。`（D5，结构文档固定句）、
`我记住了`（D1→D2 反噬链）。契约句与 D6 的第二处回指也补齐了（D6 作者欠的那笔，记在 D5 的跨章账上）。

**覆盖安装即可，进度保留。**改的是文本，`script/` 是 assets 直接挂进包的，存档里没有正文。

## 已知没验的

文本这件事没有客观验收人。我能证明的是形状（句长分布、句式复读、复读 bug）改对了，
不能证明"味道"对了。请装完之后按你自己的读法读一遍 D1——如果还有哪一句你觉得"她不会这么说"，
把那句发给我，我按那句继续改，不再重跑一遍全篇。
